Bit manipulation: the number without a twin

What this page tries: a story with no clock, where each step ends with something for the reader to do, and a look that ignores the figure rules (a dark panel of lamps whatever the theme, a monospaced face throughout, the code set as large as the drawing).

The insight

Insight

Something that undoes itself when applied twice makes pairs vanish, in any order. Here: x XOR x is 0, so XOR-ing everything together leaves only the number that has no twin.
